# REQ-003 后端接口契约

## 通用约定

- 所有接口以 `/api` 开头，返回 JSON。
- 空问题（空字符串或仅空白）一律返回 400，并带 `error` 字段。
- 开发期允许跨域（`Access-Control-Allow-Origin: *`）。

## GET /api/health

返回字段：`status`（固定 `ok`）、`api_version`、`doc_count`、`chunk_count`、`llm`。

## POST /api/ask

请求体：`{"question": string, "top_k": number}`，`question` 必填。
成功（200）返回：`answer`、`citations`（数组，元素含 `index`/`doc_id`/`chunk_id`/`score`）、
`refused`（布尔）、`retrieved`（数组）、`citation_valid`（布尔）、`latency_ms`。

## POST /api/search

请求体：`{"question": string, "top_k": number}`。
返回：`hits` 数组，按 `score` 降序，元素含 `doc_id`/`chunk_id`/`text`/`score`。

## POST /api/eval

请求体：`{"chunk_size": number, "overlap": number, "top_k": number}`。
返回：`metrics`、`gates`（数组，元素含 `metric`/`value`/`floor`/`pass`）、
`all_pass`（布尔）、`failures`（数组）、`known_issues`（数组）。

## 错误处理

- 问题为空：400 + `{"error": "question 不能为空"}`
- 其它异常：500，并在服务端日志打印堆栈，不得把堆栈返回给前端。
