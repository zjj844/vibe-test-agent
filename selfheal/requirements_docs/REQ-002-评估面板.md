# REQ-002 评估面板（/vue/ → 评估面板）

## 功能需求

### FR-1 触发评估
用户在「评估面板」标签页点击「跑一遍 gold set」按钮后，前端调用 `POST /api/eval`。

### FR-2 结果展示
接口返回后，页面展示：
- 顶部结论：全部门禁通过 或 有门禁未通过
- 指标表格，每行包含：指标名、实测值、门槛值、PASS/FAIL 判定
- 若存在失败案例，列出失败用例与原因
- 若存在已登记缺陷，单独列出

### FR-3 评估耗时
一次评估包含 12 条用例，真实模型下约需 1–3 分钟，期间按钮应处于禁用状态。

## 非功能需求

### NFR-1 门槛可配置
门槛值集中定义在一处（当前为 `evals/run_eval.py` 的 `GATES`），不得散落在代码各处。

### NFR-2 不改数据
评估过程只读，不得修改语料、gold set 或任何已存档的历史结果。
