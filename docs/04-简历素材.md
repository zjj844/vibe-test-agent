# 简历素材（项目 B）

> 这份文件是「怎么把项目写成简历」的原料，不是简历本身。
> 用法：从「简历条目」里挑 2~3 行改写，其余当面试口径背。

---

## 一、项目定位（一句话）

> **AI 增强的接口自动化测试工具**：用大模型按"需求 + 接口契约"生成 pytest 用例，
> 并带**有界自愈**（≤2 轮）与**失败归因**（5 类分流）能力；工具本身与语言无关，
> 靠一份 JSON 契约驱动，同一个工具已用于测试 Python（Flask）与 Java（Spring MVC）两个项目。

**不要这样写**（会被追问到崩）：
- ❌ "AI 测试平台" —— 没有平台（无前端、无多租户、无调度）
- ❌ "全自动修复 Bug" —— 明确不修系统 Bug（这是设计原则，不是缺陷）
- ❌ "多 Agent 协作" —— 两个模型调用点，不是多 Agent

## 二、简历条目（可直接改写，3 条）

**B1｜AI 接口测试生成 + 静态质量门禁**
基于 DeepSeek 生成 pytest 接口用例，把"文件头/请求助手/契约断言"固化为模板，模型只写测试函数；
落盘前跑 **4 道静态检查**（语法、`def test_`、接口 id 白名单、`HttpResult` 成员白名单），
把"要跑一次才知道"的错误拦在**毫秒级**；静态违规仅重试 1 次（把违规原因回喂），
实测拦截过模型虚构 API（把 `json_body` 写成 `json()`）这类**语法合法但一定崩**的错误。

**B2｜有界自愈 + 失败归因（核心差异化）**
实现"探→读→写→校验→评→快照→跑→分→定→报"十步闭环，**控制流全部写在代码里**（模型只负责"写"和"评"），
因此流程可复现、可审计、可单测。失败用**有序正则规则**分 5 类（服务不可达/系统 Bug/生成代码/断言/脚本），
每类绑定唯一动作（STOP / 出缺陷报告 / 重写 / 修），自愈最多 2 轮；
**命中"系统 Bug"时禁止改测试**——避免把缺陷改成"预期行为"（藏 Bug 比漏测更糟）。

**B3｜语言无关的契约驱动 + 登录态透明**
被测项目用一份 JSON 描述（method/path/期望状态码/期望字段/期望值/查询参数/是否带登录态），
**加一个被测项目 = 加一个 JSON**：已跑通 Python Flask 后端（`rag-backend`）；
Java Spring MVC 的 CMS（`java-cms`，含 `Authorization: Bearer` 登录链路）契约已就绪 ——
token 由工具层自动获取与注入，生成用例的模型不接触 token。

## 四、三个必答问题（面试官一定会问）

**Q：为什么不用 crewAI / LangChain Agent / 多 Agent？**
三个触发条件一个都没满足：流程是否**需要动态规划**（否，步骤固定）；是否**需要多角色协作**（否，两个调用点足够）；
失败是否**廉价且允许自由探索**（否，测试工具一自由就会乱改测试）。上了框架，调试从"看一个断点"变成"看一段推理文本"，
复现率从 100% 掉到"看运气"。**我的场景要的是可信，不是看起来智能。**

**Q：为什么不用向量数据库 / Chroma？**
需求文档只有 3 篇（22 块），检索质量靠"按标题层级分块"就能解决；引入向量库只增加部署与调试成本。
更关键的是：这一层的接口是干净的可替换点（`RequirementKB`），想换真向量只改一个类 —— **不为用而用**。

**Q：模型会不会为了通过而把断言改弱？**
三层防线：① 分类决定动作（系统 Bug 类根本不给"改测试"这个动作）；② 给模型的失败摘要只含"可修类"，
系统缺陷绝不回喂（否则等于提示它"改断言就过了"）；③ 轮数上限 2，压缩反复弱化断言的空间。

## 六、诚实边界（面试主动讲，比被追问强）

1. 自愈是**整批重写**，不是行级修复（v2 才做原位编辑）。
2. 目前**还没有**"AI 生成的用例发现了人手没发现的业务 Bug"这种样本；现阶段的真实价值是
   "低成本、持续地覆盖契约与鉴权边界"。
3. 没有接 CI、没有 Web 看板、没有历史趋势图 —— 刻意不做（见 README「刻意不做」）。

## 七、演示脚本（面试现场 3 分钟）

```bash
# 1) 测 Python 项目（服务在 8000）
python -m selfheal.loop --target rag-backend --n 3 --rounds 2

# 2) 测 Java 项目（CMS 在 8080，需登录态）
python -m selfheal.loop --target java-cms --n 3 --rounds 2
#    → 同一套代码，只换了 --target
```

一句话收尾：**"它测的不是 Python，也不是 Java，它测的是 HTTP。"**
